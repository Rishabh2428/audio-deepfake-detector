PRETRAINED ANTI-SPOOF MODEL

AASIST / AASIST-L

A graph-attention audio anti-spoofing research model. Its code and checkpoints are upstream research resources; this app does not currently load that checkpoint.

Official AASIST code ↗Checkpoint files ↗

To use AASIST in this project, the model runtime and exact input pipeline must be added and tested against a separate evaluation set. The local trainer below uses its own selected DSP feature set.

RESEARCH DIRECTION · NOT RUN BY THIS APP

Self-supervised speech representations

Recent work studies frozen WavLM or Wav2Vec2 representations paired with a small classifier to improve cross-dataset behavior. This is a promising integration candidate, but it needs a larger model runtime, compatible weights, license review, and external evaluation before it can produce AegisVoice results.

ASVspoof 2021

Challenge data and baselines for logical access, physical access, and deepfake tracks. Review access, protocol, and usage terms at the source.

ASVspoof 5

A newer challenge corpus with crowdsourced speakers, varied recording conditions, contemporary attacks, and adversarial examples. Use its official evaluation protocol and read the dataset license before importing.

Fraunhofer In-the-Wild

Real-world online recordings intended to help examine how spoof detectors behave outside controlled studio corpora.

HOW A DATASET ENTERS THIS APP

Download, label, import, evaluate

  1. Read the dataset terms and use the original dataset page linked above.
  2. Organize audio into Human and AI folders or prepare the CSV template in Train model.
  3. Import the examples, group related clips by speaker or source, then compare classifiers.
  4. Train a local model and check its grouped holdout report. Keep a separate corpus for final evaluation.

Only extracted features and label metadata are retained. The current score is an experimental model output; it is not a verified real-world probability.
