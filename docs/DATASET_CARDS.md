# Dataset cards — none imported

No audio dataset is registered or included in this workspace. The synthetic PCM fixtures generated by `tests/test_offline.py` are software test data only; they are not training data and must not be used as evidence of detection performance.

The supplied research references mention public spoofing benchmarks, but this project has not downloaded them. Before importing any corpus, create a card with the official source/version, access terms/license, speaker/generator/source conditions, label meanings, split protocol, redistribution rules, known bias, and permitted research/commercial use. Preserve official partitions and original labels. A dataset being downloadable without charge does not establish redistribution or commercial permission.
